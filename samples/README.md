# Samples

`sample_sparse.hex` contains defined bytes at `0x0000-0x000F` and `0x0020-0x0023`. It is data for file-loading and GUI tests, not executable AVR firmware.

`sample_32_bytes.bin` contains byte values `00` through `1F`. It is also test data only.
